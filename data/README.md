# Dataset Instructions

Place a permitted dataset at `data/emotion_dataset_2.csv` before running the notebook.

The CSV must contain at least these columns:

| Column | Description |
| --- | --- |
| `Emotion` | Target emotion label |
| `Text` | Input sentence or short text |

The dataset is not included in this repository. Confirm that its license allows local use and redistribution before sharing it. Remove personal or sensitive information and document the source and license in your private project notes.
