# Security Policy

## Scope

This project is an educational notebook and does not provide a hosted service or authentication system.

## Reporting a Concern

Do not open a public issue for credentials, private data, or other sensitive information. Contact the maintainer privately through the account or repository channel associated with **brajesh31**, including a description, reproduction steps, and potential impact.

Never submit real personal data or secrets in a notebook, dataset, issue, or pull request.
