# Contributing

This project is maintained as a personal research and learning repository. Contributions are not accepted without prior written approval from **brajesh31**.

Before proposing a change:

- explain the purpose and expected behavior;
- do not include private, personal, or unlicensed data;
- do not commit secrets, generated model files, or local machine paths;
- keep notebook changes focused and runnable from a clean environment; and
- verify the notebook JSON and dependency setup locally.

Unapproved copying or redistribution is prohibited by the repository license.
